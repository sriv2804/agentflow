# Skill: calculate_country_population_ratio

## When to use
Use this skill when you need to find the ratio of the population of one country to another.

## Steps
1. Search for the current population of the first country using `web_search`.
2. Search for the current population of the second country using `web_search`.
3. Use the `calculator` to divide the first population by the second population.

## Example
**Input:** What is the ratio of Brazil's population to Canada's?
**Plan:** Find populations of Brazil and Canada, then calculate the ratio.
